## Key facts

1. **Build**: `scripts/build-plugin.mjs` — esbuild `bundle: true, format: "esm", platform: "browser", target: "es2022", sourcemap: false, absWorkingDir: cwd, logLevel: "silent"`, banner `// Generated from …`. Entry `src/pi-web-plugin.ts` → `dist/pi-web-plugin.js` (name must match `piWeb.plugins[].module`). `package.json` copied verbatim to `dist/` (manifest discovery). Test files never enter the bundle (only reachable from `*.test.ts`); `.d.ts` never copied. npm deps (lit) are inlined — no host import map needed. Watch mode: `--watch`, fs.watch over src with realpath guards, 50ms debounce.
2. **For opendoor**: no vendor dir is needed initially — drop the `copyDirectory(src/vendor…)` call and the `external: ["./vendor/sysml-parser.bundle.js"]` array from the copied script (js-yaml, if vendored later by the model chain, will be inlined like lit, not kept external). Keep the rest byte-identical, rename the console tags to `[opendoor]`.
3. **tsconfig**: strict + `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `noPropertyAccessFromIndexSignature`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `allowUnreachableCode: false`, `allowUnusedLabels: false`, `noEmit`, `skipLibCheck`, `experimentalDecorators`, `useDefineForClassFields: false`, lib ES2022+DOM(+Iterable). Include `src/**/*.ts`, `src/vendor/**/*.d.ts`, `vitest.config.ts`. (For opendoor before a vendor dir exists, the vendor include glob is harmless — keep it so a later vendor drop needs no config change.)
4. **vitest.config.ts**: `test: { include: ["src/**/*.test.ts"] }`.
5. **package.json**: `type: module`, `private: true`, `files: ["dist"]`, `main: "dist/pi-web-plugin.js"`, scripts `build`/`dev`/`test` (vitest run)/`typecheck` (tsc --noEmit). Deps: `lit` runtime; peer+dev dep `@jmfederico/pi-web` (`>=1.202608` / `^1.202608.2`); dev: `esbuild ^0.27.7`, `happy-dom`, `typescript ^6.0.3`, `vitest ^4.1.10`, `@types/node ^24`. For opendoor: id `opendoor`, name `opendoor-plugin`.
6. **piWeb manifest shape**: `{"piWeb":{"plugins":[{"id":"opendoor","browserRoot":".","module":"pi-web-plugin.js"}]}}`.
7. **Host imports are type-only** — `@jmfederico/pi-web/plugin-api` exports types declarations only; at runtime the host injects everything. All host imports across src must be `import type`.
8. **Entry**: default-export `{ apiVersion: 2, name, activate: ({ runtimePluginId, html, svg }) => ({ contributions: create<Name>BrowserContributions(runtimePluginId, html, svg) }) }`. Contribution ids qualified as `${runtimePluginId}:${localId}`.
9. **Files adapter idiom**: modules define a *structural* narrow adapter interface (`listFiles`/`readFile` only) so no host import is needed; the host `context.files` and the test fake both satisfy it. Fake lives in `src/test-support.ts` (`createFakeFiles` with `trees`/`reads`/`listErrors` options, `listCalls`/`readCalls` tracking, `dirEntry`/`fileEntry`/`symlinkEntry`/`tree`/`text` helpers). Full file contents in opense-package/src/test-support.ts (117 lines) — copy and adapt names.
10. **Discovery idiom** (opense-discovery.ts): caps as exported constants (entries 2000, files 500, depth 12, concurrent reads 8), `SKIPPED_DIRECTORIES = new Set([".git", "node_modules"])`, batched reads via `Promise.allSettled` with encounter-order commit, sequential FIFO dir walk with visited-set cycle guard, never throws — all failures become diagnostics `{ severity: "error"|"warning", path?, message }`, results sorted by path.
11. **Controller idiom** (opense-panel-controller.ts): `implements ReactiveController` structurally only (never added to a real LitElement host); `OpenseWorkspaceHost { isConnected: boolean }` is a plain mutable holder (NOT a LitElement — its isConnected is read-only); every write after `await` gated on `host.isConnected`; parse() re-entrancy guard joins in-flight request and clears it only if still current; `requestUpdate()` routes through the *current* context's `host.requestRender()`. Registry: `Map` keyed by `JSON.stringify([machine.id, projectId, workspace.id])`, get-or-create refreshes `context` and bumps LRU, evicts oldest past limit (8) via `release()`. Controller passed to panel body element as property + mirrored render inputs.
12. **Contract idiom** (opense-contract.ts): single boundary module with plugin-local types + runtime guards (`requireRecord`, `requireArrayValue`, `requireString`, `requireBoolean`, …) that throw loudly on shape drift; union checks via `.some()` not `.includes()`; optional fields spread `...(x === undefined ? {} : { x })` for `exactOptionalPropertyTypes`.
13. **Build script vendor copy**: `copyDirectory` skips `.d.ts`, tolerates missing dir (ENOENT → no-op).
14. **Install**: `npm run build`, `ln -s ./dist ~/.pi-web/plugins/<id>`, verify `curl http://127.0.0.1:8504/pi-web-plugins/manifest.json`. Chain F does this — not the scaffold.
